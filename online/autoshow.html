Auto ausstellen

  1. Im Spiel: Autoshow öffnen, Auto wählen.
  2. Auf Code für Online-Show kopieren klicken.
  3. Code hier einfügen und ausstellen.
Pro Person steht ein Auto in der Show. Ein neuer Code ersetzt dein bisheriges Auto, die Stimmen bleiben dabei nicht erhalten.
