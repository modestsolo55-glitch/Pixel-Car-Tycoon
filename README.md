# AutoTycoon

Pixel-Art-Spiel im Browser: Gründe eine Autofirma, entwirf Autos und Motoren, baue die Fabrik aus – und miss dich im Drag Race.

**Spielen:** einfach `index.html` (bzw. `AutoTycoon.html`) im Browser öffnen – oder über GitHub Pages.
Auf dem Handy wird im **Querformat** gespielt.

## Inhalt
- `index.html` / `AutoTycoon.html` – das fertige Spiel (eine einzige Datei)
- `src/` – Quelldateien; `build.sh` fügt sie zu `AutoTycoon.html` und `index.html` zusammen
- `online/autoshow.html` – Seite für die Online-Autoshow

## Hinweise
- Spielstände und Konten liegen nur im Browser (localStorage), es gibt keinen Server.
- Das Test-Admin-Konto (admin / admin) ist nur lokal im eigenen Browser gültig.
